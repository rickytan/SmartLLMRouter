落地要点

  • 建议把 popover 宽度从 300 调整到 340-360，高度维持约 520-540，避免模型名和请求记录过度挤压。
  • 顶部状态需要是可操作控件：运行中显示“暂停”，暂停后显示“启动”，用于临时关闭代理但不退出菜单栏 App。
  • 顶部只放运行状态、端口和今日统计，不再把“自动故障转移”等长文案挤进同一行。
  • 模型选择和故障转移归到同一张“路由”卡片，符合 README/PRD 里模型驱动路由和自动 failover 的核心定位。
  • 最近请求用状态点 + 模型 + 时间三列，错误请求红点即可，不需要重复 selected 图标。
  • 暗色模式避免纯黑，使用深灰面板、弱边框和高对比状态色，适配 macOS 菜单栏弹窗。
